## Bitácora Consolidada y Proceso de Desarrollo

### Semana 1: Fundamentos HTML5, CSS3, Accesibilidad y W3C

#### 1. Arquitectura y Estructura Semántica (`index.html`, `tarifas.html`, `reservas.html`)
- **Organización y Bocetado:** Se diseñó la estructura base con `<header>` (navegación), `<main>` (contenido dinámico) y `<footer>` (pie de página).
- **Secciones y Artículos:**
  - *Inicio:* Uso de `<section>` para bloques principales y `<article>` para servicios independientes de alquiler (bicicletas urbanas y de montaña).
  - *Tarifas:* Tablas en secciones independientes y lista complementaria de recomendaciones en un `<aside>`.
  - *Reservas:* Formulario principal y bloque secundario `<aside>` con horarios de atención.
- **Refactorización Semántica:** Sustitución de `<div>` genéricos por etiquetas semánticas (`<nav>`, `<footer>`, `<section>`, `<article>`), dejando contenedores genéricos únicamente para soporte visual.

#### 2. Formularios y Validaciones
- **Controles Seleccionados:**
  - `<select>` para tipo de bicicleta (urbana, montaña, eléctrica), optimizando espacio y evitando errores de escritura.
  - `<input type="radio">` con atributo `name` compartido para modalidad de tarifa (hora, medio día, día completo), garantizando selección única.
  - `<textarea>` para comentarios y observaciones especiales.
- **Matriz de Pruebas y Validación de Inputs:**
  - *Documento:* Validación de campo obligatorio y formato numérico.
  - *Celular:* Requerido, patrón estricto de 10 dígitos iniciando por 3 (`^3[0-9]{9}$`).
  - *Fecha y Cantidad:* Restricción de rangos mínimos y máximos (cantidad entre 1 y 6).

#### 3. Accesibilidad y Auditoría W3C
- **Hallazgos y Correcciones:**
  - `index.html`: Inclusión del atributo `lang="es"` en la etiqueta `<html>`.
  - `index.html`: Adición de `alt=""` a imágenes decorativas para lectores de pantalla.
  - `tarifas.html`: Corrección en la jerarquía de encabezados (cambio de `<h1>` a `<h2>` directo sin saltos).
  - `reservas.html`: Vinculación explícita de etiquetas `<label for="...">` con los IDs de cada control.
- **Evaluación de Contraste y Accesibilidad Visual:**
  - Uso recomendado: *Blanco sobre Verde Ruta* (texto normal), *Azul Noche sobre Crema* (lectura general), *Verde Ruta sobre Crema* (subtítulos) y *Blanco sobre Azul Noche* (encabezados).
- **Inspección de Herencia CSS (DevTools):**
  - *Propiedades heredadas:* `color` (heredado desde `body`).
  - *Propiedades no heredadas:* `background-color` (valor por defecto `transparent`).
  - *Especificidad:* Solución de conflictos visuales en `#menu` y `.active` sin recurrir a `!important`.

#### 4. Modelo de Caja (Box Model) y Ajustes Visuales (v1.0)
- **Cálculo de Ancho:** Aplicación global de `box-sizing: border-box`, corrigiendo desbordamientos al incluir *padding* y *border* dentro de las dimensiones fijas.
- **Posicionamiento:**
  - Etiqueta flotante `"Nuevo"` en la tarjeta de bicicletas eléctricas mediante `position: absolute`.
  - Botón flotante de atención vía **WhatsApp** mediante `position: fixed` en la esquina inferior derecha.

### Semana 2: Diseño Adaptable (Responsive), Layouts y Bootstrap 5

#### 1. Comportamiento Responsive y Breakpoints
- **Breakpoints:** Pruebas de adaptación a 360 px (móvil, 1 columna), 768 px (tablet, 2 columnas / apilamiento de menú), 900 px y 1280 px (escritorio, 3 a 4 columnas).
- **Estrategia de Layout:**
  - *Grid:* Usado en Portada (2 columnas), Galería de Rutas (3 tarjetas en fila) y Reservas (proporción 2:1 para formulario e información).
  - *Flexbox:* Usado en filas internas del formulario, Header (título a un lado, menú al otro) y Footer (bloques horizontalmente alineados).
- **Resolución de Hallazgos Responsive:**
  - *Tablas desbordadas en 360 px:* Reducción de tipografía y padding en `th` y `td`.
  - *Apilamiento de Header:* Ajuste con `flex-direction: column` en móvil y `flex-direction: row` a partir de 768 px.
  - *Imágenes rígidas:* Regla global `max-width: 100%; height: auto;`.

#### 2. Implementación y Métricas de Bootstrap 5
- **Reducción de Código:** Reducción de más de 25 líneas de CSS propio (flexbox y media queries manuales) a 0 líneas mediante el uso de clases de grilla nativas (`row`, `g-3`, `col-12`, `col-sm-6`, `col-lg-4`, `col-xl-3`).
- **Tiempo de Maquetación:** ~10 minutos para la maquetación adaptable base frente al tiempo invertido en CSS nativo.

### Semana 3: Tailwind CSS, Landing Rueda Nocturna e Integración

#### 1. Comparativa de Enfoques (Bootstrap vs. Tailwind CSS)
- **Metodología:** Transición de componentes rígidos (`btn btn-primary`) a clases de utilidad atómicas (`inline-block bg-emerald-500 text-slate-950 font-bold px-6 py-3 rounded-xl`).
- **Optimización CLI:** Uso de Tailwind CLI con compilación minificada (`--minify`), generando un paquete CSS final optimizado de **12.4 KB** mediante *Tree-shaking*, en comparación con los **145.8 KB** (CSS + JS) de Bootstrap 5.

#### 2. Estandarización del Kit de Componentes
- **Bordes:** `rounded-2xl` para contenedores y tarjetas principales; `rounded-xl` para botones, inputs y alertas.
- **Espaciados:** `p-6` en tarjetas, `p-4` en componentes secundarios y `space-y-4` para separación vertical.
- **Paleta:** Base `slate-800` / `slate-900` para modo oscuro (`dark`), con acentos en verde esmeralda (`emerald-500` / `emerald-400`) y amarillo farol.

#### 3. Corrección de Rutas Relativas y Bitácora de Errores
- **Diagnóstico del Error 404 / File Not Found:** Ocurrió al abrir los archivos directamente desde el explorador de archivos (`C:\Users\...`) o por enlaces mal configurados (`/promociones.html`).
- **Solución Implementada:** 
  - Uso obligatorio de servidor local (Live Server / `http://127.0.0.1:5500`).
  - Estandarización de rutas relativas con navegación ascendente y descendente (`../index.html` para regresar a la raíz desde subcarpetas como `paginas/` o `RuedaNocturna/`).

#### 4. Sección de Planes Rueda Nocturna (MiniReto Tailwind)
- **Estructura Responsiva:** Grid de 1 columna en móviles y 3 columnas en pantallas grandes (`lg:grid-cols-3`).
- **Igualdad de Altura y Alineación:** Uso de `flex flex-col justify-between` en cada tarjeta para garantizar la misma altura y que los botones queden perfectamente alineados en la parte inferior.
- **Plan Pareja Destacado:** Resaltado visual con borde reforzado en verde esmeralda (`border-4 border-emerald-500`), fondo con degradado elegante, textos contrastados y la insignia superior flotante `"★ Más elegido ★"`.

## Cuadro Comparativo de Rendimiento

| Criterio | Bootstrap 5 (Sitio Principal) | Tailwind CSS (Rueda Nocturna) |
| **Enfoque** | Componentes preconstruidos con estilos rígidos. | Utilidades atómicas de bajo nivel directas en el HTML. |
| **Personalización** | Requiere sobrescribir reglas CSS o compilar Sass. | Libre y configurable mediante configuración de temas y utilidades. |
| **Peso final del CSS** | ~145.8 KB (108.2 KB CSS + 37.6 KB JS). | **12.4 KB** (compilado y minificado con Tailwind CLI). |
| **Caso de uso** | Ideal para prototipado rápido y estructuras estándar. | Ideal para landings personalizadas, modo oscuro y máxima velocidad. |
